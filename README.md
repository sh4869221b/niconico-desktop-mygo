# Niconico Desktop MyGo

Windows用の非公式ニコニコブラウザです。[C#版](https://github.com/sh4869221b/niconico-desktop)とは別プロジェクトです。検索結果、投稿動画、マイリスト、動画詳細はGoと[MyGo](https://github.com/egoist/mygo)の独自UIで表示します。通常の画面はWebView2なしで表示でき、公式ログインとコメント弾幕付きの再生は必要なときだけWebView2を開きます。プレーヤーは1つの別ウィンドウを使い回し、検索画面を残します。

## 使い方

- **検索 / タグ検索**：キーワードや完全一致タグで検索します。検索欄には動画IDや公式URLも入力できます。「並べ替え」はニコニコ動画の検索画面と同じ項目から選べます。通常検索に接続できない場合、未ログイン時の一部の並べ替えは[スナップショット検索API](https://site.nicovideo.jp/search-api-docs/snapshot)に切り替わります。その場合はフッターに「スナップショット検索」と表示され、結果の更新時刻が異なります。
- 一覧の「最初のページ」は検索条件を保ったまま先頭へ戻ります。検索画面で変更した並べ替えは次回起動時にも使われます。検索結果のタグと投稿者名から、それぞれタグ検索と投稿動画一覧を開けます。
- **動画詳細 / 再生**：概要欄の動画IDとマイリストID、ニコニコ公式のリンクをアプリ内で開けます。「再生」、動画サムネイル、概要欄の動画リンクは設定で選んだプレーヤーを別ウィンドウで開きます。動画詳細や独自プレーヤーのタグを押すと、メインウィンドウでタグ検索できます。
- **シリーズ**：ユーザーの投稿動画画面や独自プレーヤーの「シリーズ」から、投稿者のシリーズ一覧を閲覧できます。シリーズを選ぶと動画一覧が開き、動画のサムネイルから再生できます。
- **ログイン / 自分のマイリスト**：公式ログインの共有セッションを検索、マイリスト、再生ウィンドウで使います。ツールバーにニコニコのログイン状態を表示し、「再確認」で更新できます。パスワードやCookieをアプリ独自のファイルに保存せず、認証Cookieは対象のニコニコ公式APIのリクエストにだけ使います。外部事業者によるログインは対象外です。
- **☆ 登録 / 視聴履歴**：検索条件、動画、ユーザーやマイリストのリンクを端末内に登録できます。検索結果の固定保存やニコニコ側のマイリスト変更は行いません。公式プレーヤーで開いた動画は最大100件まで記録します。
- **URLをコピー**：投稿動画一覧や個別マイリストで、[go-nico-list](https://github.com/sh4869221b/go-nico-list)用の正規URLをコピーできます。認証状態は共有しないため非公開リストはgo-nico-listでは取得できません。
- **接続できない場合**：動画の公開情報が取得できなくても、公式プレーヤーを試せます。投稿一覧やマイリストは「公式ページ」を開けます。

登録済み項目と履歴は `%APPDATA%\NiconicoDesktopMyGo\library.json` に保存します。同じMyGo版からの更新では、既存の登録済み項目・視聴履歴とWebView2のセッションを引き継ぎます。C#版からは自動移行しません。

## ビルド

Windows 10/11 x64が対象です。公式画面やログイン状態の利用には [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) が必要です。ビルドにはGo 1.27.3以降を使います。

```powershell
go test ./...
go build -trimpath -ldflags=-H=windowsgui -o NiconicoDesktopMyGo.exe .
```

GitHub Actionsの「Windows build」はテスト、静的チェック、Windows x64のビルドを実行し、試用ZIPとSHA-256を成果物として保存します。タグを push するか、`main`で「Windows build」を開いて`vMAJOR.MINOR.PATCH`を指定すると、上記のチェックに合格したファイルだけをGitHub Releasesへ公開します。

公開版はScoopの`mybucket/niconico-desktop-mygo`で導入できます。C#版とは別パッケージです。

## ダウンロードと初回起動

配布元はこのリポジトリの [GitHub Releases](https://github.com/sh4869221b/niconico-desktop-mygo/releases) です。ZIP 版は同じリリースの `NiconicoDesktopMyGo-win-x64.zip` と `SHA256SUMS.txt` を取得し、展開・起動前に PowerShell で照合できます。

```powershell
$line = @(Get-Content .\SHA256SUMS.txt | Where-Object { $_ -match '^[0-9a-fA-F]{64}  NiconicoDesktopMyGo-win-x64\.zip$' })
if ($line.Count -ne 1) { throw '対象 ZIP の SHA-256 を確認できません。' }
$expected = ($line[0] -split '  ')[0].ToLowerInvariant()
$actual = (Get-FileHash .\NiconicoDesktopMyGo-win-x64.zip -Algorithm SHA256).Hash.ToLowerInvariant()
if ($actual -cne $expected) { throw 'SHA-256 が一致しません。起動せず、配布元を確認してください。' }
'公開された SHA-256 と一致しました。'
```

一致は同じ配布元の ZIP と検証値の整合を確認するものです。発行元のコード署名を証明するものではありません。v0.3.0 の初回実機確認では EXE は未署名でした。展開した版の署名状態は次で確認できます。

```powershell
Get-AuthenticodeSignature .\NiconicoDesktopMyGo.exe | Format-List Status,SignerCertificate
```

Windows の警告は、取得方法や端末のポリシーによって異なります。警告が出たら表示されたファイル名・発行元・配布元を確認し、不明な場合は起動を中止してください。警告が出なかったことだけでは安全性を判断できません。防御機能や組織のポリシーを無効にする操作は案内しません。Scoop 版を使う場合もパッケージ名 `mybucket/niconico-desktop-mygo` と配布 URL・ハッシュを確認してください。

ZIP / Scoop の初回表示の比較手順と未検証項目は [検証記録](docs/validation/issue-59.md) にあります。

## 再生プレーヤーの選択

上部の「設定」から選択できます。切り替えは次に動画を開くときに反映され、アプリを閉じても保持されます。どちらも再生は別ウィンドウです。

- **公式 WebView（既定）**: 従来どおりニコニコ公式のプレーヤーを使います。
- **独自プレーヤー（試験版）**: Windows Media Foundation とアプリ独自の再生操作・日本語コメント表示を使います。ログインは引き続きニコニコ公式画面で行います。公式と同じ弾幕表示、コメント投稿、すべての配信形式・視聴条件には対応していません。
- 独自モードの「公式 WebView で開く」は、その動画だけを公式プレーヤーで開き直します。設定は変わりません。
- 「概要欄を表示」で映像の上に概要欄を開きます。コメント一覧も同時に表示できます。「投稿動画」は再生を続けながら、メインウィンドウに一覧を開きます。
- 独自モードでは、Windowsで最初の映像を表示できるまで音声を保留します。映像をクリックして再生と一時停止を切り替えられます。コメント一覧は再生位置に追従し、手動操作で止まります。「再生位置に追従」で再開できます。行を右クリックすると、そのユーザーのコメントを一覧と弾幕で非表示にできます。「NG管理」で解除できます。匿名IDのNGは動画ごとに適用し、設定は端末内に保存します。

独自モードではニコニコが許可した HLS 配信を読み取ります。再生に必要な配信 Cookie は、その再生中だけ有効なローカル中継が使い、ログイン Cookie は動画情報と再生許可を取得するためのニコニコの限定された経路にのみ送信します。

独自プレーヤーの日本語コメントは、公式プレーヤーに近いサイズ・色・縁取り・スクロールで表示します。上下固定や複数行にも対応し、空きレーンを優先します。混雑時の重なり方、特殊なコメントアート、ニコニコ側のコメント絞り込みは公式と同一ではありません。
